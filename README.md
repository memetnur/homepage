# Homepage

Private source repository for `www.nurmemeti.com`, built as a Linktree-style personal homepage.

## Files

- `index.html`: static homepage template
- `styles.css`: site styling
- `CNAME`: custom domain marker for `www.nurmemeti.com`

## Hostpoint

For direct Hostpoint hosting, upload `index.html` and `styles.css` to the web root for `www.nurmemeti.com`.

If this repository is later served through GitHub Pages, keep `CNAME` in the repository and configure Hostpoint DNS according to GitHub Pages' custom-domain instructions.
